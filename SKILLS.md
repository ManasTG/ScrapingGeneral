## Agent Development Rules

- Prefer FastAPI over Flask.
- Use Selenium only when JavaScript rendering is required.
- Use BeautifulSoup for HTML parsing after page retrieval.
- Create reusable scraper modules.
- Separate scraping logic from UI logic.
- Store selectors in configuration files.
- Implement retry mechanisms.
- Implement graceful failure handling.
- Use explicit waits instead of time.sleep().
- Build APIs before frontend integration.
- Generate fully typed Python code.
- Include logging in all modules.
- Create unit tests for critical functionality.
- Follow SOLID principles.
